# 报告摘要卡 + 中文排版 + 图的对称 设计（2026-11-02）

## 为什么

上游报告的框架是"论证在前、结论在后"（组合经理决策是第五节），且其 CSS 为英文衬线体调校
（`--serif` 无任何中文字族、正文 17px/1.62），中文读起来节奏不对、重点不突出。卖方报告的惯例
是结论先行。磁盘产物是内核的、呈现是我们的：这两件事都落在已有的呈现层 `report_page.py`，
上游零改动。

## 目标 / 非目标

**目标**

- 中文运行的报告在页首（masthead 之后、目录之前)出现**核心结论卡**：组合经理结论的摘录 +
  "阅读完整结论"锚点；原文第五节原样保留。
- 中文运行的报告注入一段 `ta-cn` 样式：正文衬线栈补中文字族（Noto Serif CJK / 思源宋体 / 宋体）、
  行距按中文调到 1.85、标题无衬线栈补中文。
- 流程图宽屏布局：分析师一行**动态居中对齐多头研究员中心**（选 1/2/4 个都对称）。

**非目标**

- 不重排五个章节的顺序（编号会乱，收益不比摘要卡大）。
- 不改英文运行的报告（逐字节不变，现有测试锁定）。
- 不动 `complete_report.md` / `.html` 的磁盘内容。
- 不动窄屏图的记忆检索位置（已登记为 deferred minor）。

## 方案（已与用户确认：C + A，图的对称顺手修）

- **C 排版**：`present()` 在 `</head>` 前注入 `<style id="ta-cn">`，只覆盖 `--serif`/`--sans`
  两个字族变量与 `body` 行距；暗色与打印沿用上游变量，无需另写。
- **A 摘要卡**：以 `<h3 id="sN-1">Portfolio Manager</h3>` 为锚（该标题不翻译、结构稳定），取其
  所在 `<section>` 内 h3 之后的正文，摘前两个 `<p>`；无段落则取前 500 字符。卡插在 `</header>`
  之后。英文运行不注入。
- **图对称**：`progress_graph.py` 宽屏分析师行改为按所选数量计算起点，使组中心 = bull 中心
  （355px）；memory 跟在行尾。窄屏本就对称，不动。

## 耦合与守卫

新增依赖的上游标记：`</head>`、`</header>`、`<h3 id="s`、`Portfolio Manager</h3>`、
`--serif:`、`--sans:`。全部并入 `UPSTREAM_MARKERS`，守卫测试改为对真实 `render_report()` 输出
断言（本次一并把守卫夹具补上组合经理一节）。`docs/UPSTREAM_DELTA.md` 脆弱耦合栏同步登记。

## 验收

- 中文报告：摘要卡在页首、含摘录与 `#sN` 锚点；第五节原文不变；`ta-cn` 样式恰出现一次；
  `present()` 幂等。
- 英文报告：与上游产物逐字节一致。
- 图：1/2/4 个分析师时宽屏组中心与 bull 中心偏差 ≤1px；既有几何测试全绿。
